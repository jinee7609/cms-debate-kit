# CMS Debate Kit

Turn a supplied book excerpt into a classroom-ready debate kit while preserving strict traceability to the source.

## Before creating files

1. Inspect the excerpt, paragraph numbering, existing templates or debate rules, and the destination project without changing them.
2. State the proposed deliverables, filenames, expected result, and absolute save paths.
3. Obtain explicit user approval before creating, moving, renaming, or modifying files. Perform only the approved changes; request approval again for additions.
4. If paragraphs are not numbered, do not silently invent permanent source numbering. Propose a temporary numbering method and obtain approval before using it.

## Source boundary

- Use only the supplied excerpt as evidence. Do not introduce facts, plot details, authorial intent, historical context, or interpretations that require material outside the excerpt.
- When the excerpt does not support a claim, write exactly `발췌문에서 확인 불가`. Do not fill gaps by guessing.
- Distinguish source statements from reasoning. Interpretations may connect quoted evidence to the proposition, but must not be presented as facts stated by the excerpt.
- Mark uncertain facts or figures as `확인 필요` unless the excerpt directly verifies them.

## Quotation rules

- Copy quotations verbatim, preserving wording, spelling, punctuation, and meaningful omissions.
- Attach the source paragraph number to every quotation.
- Never turn a paraphrase into quotation marks. Label paraphrases as summaries and still cite the supporting paragraph number.
- If an excerpt has page numbers as well as paragraph numbers, paragraph numbers remain required; page numbers may be added as secondary locators.

## Workflow

### 1. Analyze the excerpt

- Identify the excerpt's explicitly stated conflicts, choices, values, causes, consequences, and unresolved questions.
- Build a traceability map from candidate issues to supporting paragraph numbers.
- Exclude candidate issues that require outside knowledge or lack usable support in the excerpt.

### 2. Draft debate propositions

- Create propositions that are arguable from more than one side and narrow enough for the available excerpt.
- For each proposition, confirm that both sides can point to excerpt evidence. Otherwise revise it or mark the unsupported side `발췌문에서 확인 불가`.
- Avoid wording that assumes disputed outside facts.

### 3. Create evidence cards

Each card should contain, when appropriate:

- proposition and side;
- claim;
- verbatim quotation with paragraph number;
- reasoning that explains how the quotation supports the claim;
- possible counterargument or limitation;
- verification status.

Keep claims, quotations, and reasoning visually distinct. A card without adequate source support must show `발췌문에서 확인 불가` instead of fabricated evidence.

### 4. Create worksheets and rubric

- Make the worksheet guide learners from proposition interpretation through claim, evidence, reasoning, rebuttal, and reflection.
- Make rubric criteria observable and aligned to the worksheet. Include source fidelity, quotation accuracy, paragraph-number citation, reasoning quality, counterargument handling, and completion.
- Do not award evidence credit for unsupported outside material.
- Preserve any supplied template or debate-rule file as an untouched original; create a new derivative in the destination folder.

### 5. Verify citations

Before delivery, audit every quotation and evidence claim against the excerpt:

1. Locate the cited paragraph.
2. Compare the quotation character by character for wording and punctuation.
3. Confirm the paragraph number.
4. Confirm that the linked claim does not exceed what the quotation supports.
5. Replace unsupported material with `발췌문에서 확인 불가` or revise the claim.

Record verification results in a compact table with the item, cited paragraph, quotation match, support judgment, and required correction.

## File handling and delivery

- Never modify, rename, move, overwrite, or delete source excerpts, debate rules, forms, or other input originals.
- Save all new documents, code, and reports under the target project's `결과물` folder. Create that folder only after approval if it does not exist.
- Use new filenames and avoid collisions; ask before changing an approved filename or path.
- At completion, report the changes, number of files, and final absolute paths. Summarize created files and remaining review items in a table.
